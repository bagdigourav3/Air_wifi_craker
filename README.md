# Air_wifi_craker
Air_wifi_craker is a Python 3 WiFi security testing tool. It scans nearby networks, lists them in a banner UI, and cracks WPA/WPA2 handshakes with aircrack-ng. Install: sudo apt install aircrack-ng network-manager wireless-tools, then run: sudo python3 Air_wifi_craker.py. For authorized penetration testing only. Commands to install in the readme.md
